# Putt Podium

Mini-golf scorekeeping, standings and sharing.

## Download

[Download source ZIP](https://github.com/eire360/putt-podium/archive/refs/heads/main.zip)

## Setup

Requires Xcode and an iPhone simulator or device.

1. Open `putt podium.xcodeproj`.
2. Select a simulator and run.
3. Add players, select the hole count, and start a round.

For a physical iPhone, choose your own development team under Signing & Capabilities.

## Controls

Add players, adjust scores for each hole, and view/share the final standings.
